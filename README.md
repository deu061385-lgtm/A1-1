# 나만의 프롬프트 관리 프로그램

GenAI 미션들을 진행하며 쌓인 프롬프트를 한곳에서 체계적으로 관리하기 위해 만든
파이썬 콘솔 기반 프로그램입니다. 프롬프트를 등록하고, 카테고리별로 조회하고,
키워드로 검색하고, 즐겨찾기로 관리할 수 있습니다.

## 실행 방법

1. Python 3.10 이상이 설치되어 있어야 합니다. (개발 환경: Python 3.14.7)
2. 이 저장소를 클론하거나 다운로드합니다.
3. 프로젝트 폴더로 이동한 뒤 아래 명령어를 실행합니다.

   ```bash
   python main.py
   ```

4. 메뉴에 표시되는 번호를 입력해 원하는 기능을 실행합니다.
5. `0`을 입력하면 프로그램이 종료됩니다.

> 프로그램 실행 중 추가한 프롬프트와 즐겨찾기 상태는 프로그램이 실행되는 동안에만 유지되며,
> 종료 시 초기화됩니다. (별도 파일 저장 기능은 포함되어 있지 않습니다.)

## 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 입력해 새 프롬프트를 등록합니다. 빈 값 입력 시 재입력을 요청합니다. |
| 2 | 프롬프트 목록 | 등록된 모든 프롬프트를 번호, 카테고리, 즐겨찾기 여부(⭐)와 함께 출력합니다. |
| 3 | 카테고리별 조회 | 카테고리를 선택하면 해당 카테고리에 속한 프롬프트만 조회합니다. |
| 4 | 프롬프트 검색 | 키워드를 입력하면 제목 또는 내용에 포함된 프롬프트를 검색합니다. |
| 5 | 프롬프트 상세 보기 | 번호를 입력하면 제목, 카테고리, 즐겨찾기 여부, 내용 전체를 출력합니다. |
| 6 | 즐겨찾기 관리 | 번호를 입력해 해당 프롬프트의 즐겨찾기 상태를 추가/해제합니다. |
| 7 | 즐겨찾기 목록 | 즐겨찾기로 등록된 프롬프트만 모아서 조회합니다. |
| 0 | 종료 | 프로그램을 종료합니다. |

## 등록된 프롬프트 카테고리

- **텍스트 생성**: 블로그, 요약, 답변 등 텍스트 생성용 프롬프트
- **이미지 생성**: 이미지 생성 AI에 사용하는 프롬프트
- **영상 생성**: 영상 제작/기획에 사용하는 프롬프트
- **페르소나**: 특정 역할이나 전문가 페르소나를 부여하는 프롬프트
- **자동화**: 노코드 자동화 워크플로우 관련 프롬프트
- **기타**: 위 카테고리에 속하지 않는 프롬프트

프로그램 시작 시 이전 미션에서 실제로 작성했던 프롬프트 3개가 기본 데이터로 등록되어 있습니다.

- 회의록 요약 시스템 프롬프트 (텍스트 생성)
- FreshKeeper UI 디자인 이미지 생성 (이미지 생성)
- 구글시트 응답 자동 이메일 발송 (자동화)

## 코드 구조

기능별로 함수를 분리하여 작성했습니다.

- `show_menu()` : 메뉴 출력
- `add_prompt()` : 프롬프트 추가
- `show_list()` : 프롬프트 목록 조회
- `show_by_category()` : 카테고리별 조회
- `search_prompt()` : 프롬프트 검색
- `show_detail()` : 프롬프트 상세 보기
- `toggle_favorite()` : 즐겨찾기 추가/해제
- `show_favorites()` : 즐겨찾기 목록 조회
- `main()` : 메인 실행 및 메뉴 분기
