【1. 미션 개요】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

파이썬으로 프롬프트 관리 프로그램을 만들고
Git/GitHub로 버전 관리까지 완성하는 과제입니다.

【최종 결과물】
- Python 콘솔 프로그램 1개
- GitHub 저장소 1개 (커밋 10개 이상, 브랜치 1회 이상)

【필수 기능】
1. 프롬프트 추가
2. 프롬프트 목록 보기 (번호, 제목, 카테고리, 즐겨찾기⭐)
3. 카테고리별 조회
4. 프롬프트 검색 (제목/내용 키워드)
5. 프롬프트 상세 보기
6. 즐겨찾기 추가/해제
7. 즐겨찾기 목록 보기

【데이터 구조】
prompts = [

- Python 3.10 이상
- 외부 라이브러리 사용 금지
- 기능별 함수 분리 필수
- 기본 데이터 최소 3개 이상 등록

- 브랜치 생성 및 병합 1회 이상
- init, add, commit, push, pull, checkout, clone, merge 각 1회 이상

【보너스 과제】
- JSON 파일로 저장/불러오기
- Markdown으로 내보내기
- 수정/삭제 기능
- 조회수 기록 및 Top 목록

def show_menu():
    print("=== 프롬프트 관리 프로그램 ===")
    print("1. 프롬프트 추가")
    print("2. 프롬프트 목록 보기")
    print("3. 프롬프트 검색")
    print("4. 프롬프트 수정")
    print("5. 프롬프트 삭제")
    print("0. 종료")

def main():
    while True:
        show_menu()
        choice = input("선택하세요: ")
        if choice == "0":
            print("프로그램을 종료합니다.")
            break

if __name__ == "__main__":
    main()
